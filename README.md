# Steam Clone 🎮

Proyecto web tipo Steam desarrollado con PHP, CSS y JavaScript.

## Vista previa

![vista previa](https://via.placeholder.com/800x400?text=Steam+Clone+Preview)

## Características
- Catálogo de videojuegos
- Carrito visual (localStorage)
- Panel de administración
- Diseño responsivo y moderno

⚠️ Este repositorio solo muestra el frontend y backend sin conexión activa a base de datos.  
Para ejecutarlo correctamente se debe usar en servidor local con XAMPP o similar.
